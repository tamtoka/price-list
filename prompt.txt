Напиши CLI-скрипт на Python для Windows.

В папке проекта есть:
- products.csv со столбцами product,price,qty;
- template.html с шаблоном Jinja2, который перебирает items.

Скрипт должен:
1. Прочитать все товары из CSV в кодировке UTF-8.
2. Подставить их в HTML-шаблон.
3. Создать один PDF с таблицей всех товаров, сохранив
   оформление и корректное отображение русского текста.
4. Сохранить PDF в подпапку output внутри проекта.
   Если папки нет, создать её.
5. Автоматически открыть готовый PDF в Windows.

Укажи необходимые зависимости и команды установки
и запуска. Объясни код понятным для новичка языком.
